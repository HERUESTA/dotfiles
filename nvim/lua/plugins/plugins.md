# Neovim Plugins

`nvim/lua/plugins/` 配下で利用している主要プラグインの概要です。

## Plugin list

- **bufferline.nvim**: バッファをタブラインに一覧表示し、開いているファイルを素早く切り替えるためのプラグインです。
- **catppuccin**: Catppuccin テーマを提供し、エディタ全体の配色を統一するためのカラースキーマプラグインです。
- **conform.nvim**: 保存時や手動実行でコードフォーマッタを呼び出し、ソース整形を統一するためのプラグインです。
- **flash.nvim**: 画面内ジャンプを高速化し、文字列や位置への移動操作を効率化するためのナビゲーションプラグインです。
- **friendly-snippets**: 多言語向けのスニペット集を提供し、補完エンジンから定型コードを展開しやすくするためのプラグインです。
- **fzf-lua**: ファイル検索・文字列検索・各種ピッカーを fuzzy finder で実行するためのプラグインです。
- **gitsigns.nvim**: Git の差分を行番号横に表示し、hunk 単位の操作や履歴確認を行うためのプラグインです。
- **grug-far.nvim**: プロジェクト全体の検索・置換を UI 付きで安全に実行するためのプラグインです。
- **lazy.nvim**: Neovim のプラグイン管理を行い、遅延読み込み・依存解決・更新管理を担当するプラグインマネージャです。
- **lazydev.nvim**: Lua 開発体験を向上させ、Neovim 設定やプラグイン開発時の型情報や補完を強化するためのプラグインです。
- **mason-lspconfig.nvim**: Mason で導入した LSP サーバーを nvim-lspconfig と連携し、設定を簡単にするためのブリッジプラグインです。
- **mini.ai**: テキストオブジェクト（関数・括弧・単語など）の選択/操作を強化するためのプラグインです。
- **mini.icons**: ファイル種別などに応じたアイコン表示を提供し、UI の視認性を高めるためのプラグインです。
- **mini.pairs**: 括弧やクォートの自動ペア入力を行い、タイピング効率を上げるためのプラグインです。
- **noice.nvim**: メッセージ・コマンドライン・通知 UI を拡張し、Neovim の表示体験を改善するためのプラグインです。
- **nvim-lint**: 外部リンターを Neovim から実行し、構文・品質チェック結果を表示するためのプラグインです。
- **nvim-treesitter-textobjects**: Tree-sitter の構文情報を使って、関数やクラスなど構造単位の選択・移動を可能にするプラグインです。
- **nvim-ts-autotag**: HTML/JSX などのタグ編集時に開始タグ・終了タグを自動同期するためのプラグインです。
- **persistence.nvim**: セッション情報を保存・復元し、再起動後に作業状態を素早く再開できるようにするプラグインです。
- **SchemaStore.nvim**: JSON/YAML などのスキーマ定義を提供し、LSP の補完やバリデーション精度を上げるためのプラグインです。
- **todo-comments.nvim**: コード中の TODO/FIXME/NOTE などを強調表示し、一覧ジャンプしやすくするためのプラグインです。
- **tokyonight.nvim**: TokyoNight テーマを提供し、エディタの見た目を統一するためのカラースキーマプラグインです。
- **ts-comments.nvim**: Tree-sitter を使って言語ごとのコメント挿入/トグルを正しく処理するためのプラグインです。
- **which-key.nvim**: キー入力途中の候補をポップアップ表示し、キーマップを発見しやすくするためのプラグインです。
